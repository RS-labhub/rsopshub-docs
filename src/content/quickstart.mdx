## Prerequisites

- **Node.js 20+**
- **[Bun](https://bun.sh)** (used for installing dependencies and running scripts)
- **PostgreSQL 14+**, running locally or on a managed host such as Neon or Supabase

### Install PostgreSQL

If you already have a running PostgreSQL instance, skip ahead.

**macOS (Homebrew)**

```bash
brew install postgresql@17
brew services start postgresql@17
createdb rsopshub
```

**Linux (Debian / Ubuntu)**

```bash
sudo apt update
sudo apt install postgresql postgresql-contrib
sudo systemctl start postgresql
sudo -u postgres createdb rsopshub
```

**Windows (EDB installer)**

Download the installer from [postgresql.org/download/windows](https://www.postgresql.org/download/windows/), run it, and use pgAdmin or the SQL Shell to create a database called `rsopshub`.

<Steps>
  <Step title="Clone and install">
    ```bash
    git clone <repo-url> rsopshub
    cd rsopshub
    bun install
    ```
  </Step>
  <Step title="Configure environment variables">
    ```bash
    cp .env.example .env
    ```

    Open `.env` and fill in the six required values:

    | Variable | What to set |
    |---|---|
    | `DATABASE_URL` | PostgreSQL connection string, for example `postgresql://postgres:secret@localhost:5432/rsopshub?schema=public` |
    | `OWNER_EMAIL` | Your email address (the only account that can sign in as owner) |
    | `OWNER_PASSWORD` | A strong passphrase, at least 12 characters |
    | `SESSION_SECRET` | At least 32 random characters (used to sign session cookies) |
    | `TOKEN_ENC_KEY` | At least 32 random characters (AES-GCM key for encrypting stored API tokens) |
    | `APP_URL` | `http://localhost:3000` for local development |

    You can generate random secrets with:

    ```bash
    openssl rand -base64 48
    ```

    Every other variable in `.env.example` is optional. Integrations such as Notion, Google, and Linear stay disabled until you add their credentials later.
  </Step>
  <Step title="Push the database schema">
    ```bash
    bunx prisma db push
    ```

    This creates all tables in your PostgreSQL database. No migration history is needed for a fresh setup.
  </Step>
  <Step title="Seed sample workspaces (optional)">
    ```bash
    bun run db:seed
    ```

    The seed script creates two empty workspaces, **Tessl** and **LLMWare**, each with a generated 16-character viewer access code printed to the console. This step is optional. The app handles a fresh, empty database without it, and the welcome screen will prompt you to create your first workspace.
  </Step>
  <Step title="Start the dev server">
    ```bash
    bun run dev
    ```

    Open [http://localhost:3000](http://localhost:3000) in your browser. Sign in with the `OWNER_EMAIL` and `OWNER_PASSWORD` you set in `.env`. You should see the home screen with either the seeded workspaces or a prompt to create one.
  </Step>
</Steps>

## Production build

```bash
bun run build
bun run start
```

`bun run build` generates the Prisma client and produces an optimized Next.js build. `bun run start` serves it on port 3000 by default.
